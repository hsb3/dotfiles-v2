# helix

## What

The Helix editor (`hx`), set as `EDITOR` and `VISUAL` via
`~/.config/zsh/conf.d/helix.zsh`. Config in `~/.config/helix/config.toml`.

## Install

`./install.sh` installs `helix` and links both files.

## Customize

Edit `home/.config/helix/config.toml`. Check the setup with `hx --health`.

## Verify

`./verify.sh` checks the Brewfile is satisfied and both files are linked.
